
سین‌شین فودپارک
اپلیکیشن سفارش غذا — تک‌سرور، غیرمیکروسرویس، تیم کوچک.یک فایل کامپوز برای کل استک؛ نه فایل جدا برای هر اپ، نه شبکه‌ی دستی، نه پیش‌نیاز پنهان.

معماری
اینترنت ──▶ caddy (TLS) ──▶ web  ← فرانت TanStack Start (SSR)                        └──▶ api  ← بک‌اند Elysia + Bun  (مسیر /api/*)                              ├──▶ postgres 18.6                              └──▶ redis 8
کل استک با یک دستور از ریشه بالا می‌آید.
سرویس migrate قبل از api اجرا می‌شود و مهاجرت‌های دیتابیس را اعمال می‌کند (بر اساس journal خودِ drizzle، تکرار-execution بی‌ضرر است).
دیتابیس و ردیس در شبکه‌ی بسته هستند؛ از بیرون فقط caddy دیده می‌شود.
swagger / openapi فقط وقتی فعال باشد که در .env ریشه روشنش کرده باشی.
